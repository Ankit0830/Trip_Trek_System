How can implemt Regex for Validation usename and password.

  1.Username Validation (Only Alphabets):-  
  Regex: [a-zA-Z]+
  This allows only alphabet characters and at least one character

  2.Password Validation (Letters, Digits, Dot):- 
  Regex: ^[a-zA-Z0-9.]+$
  This ensures the password contains only allowed characters.
